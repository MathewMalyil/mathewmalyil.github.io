ReadFlow Speed Reader

Help, troubleshooting, and contact information for ReadFlow Speed Reader.

About the App

ReadFlow Speed Reader helps you read your own content with focused reading modes, speed controls, OCR, file import, clipboard reading, and Safari sharing.

Supported Inputs

  • PDF files
  • TXT, RTF, Markdown, HTML, and DOCX documents
  • Copied or pasted text
  • Web article links
  • Safari shared pages
  • Screenshots and photos containing readable text
  • Camera scans of printed text

How to Import Content

  • Use Import File to choose a document from Files.
  • Use Scan Text to capture printed text with the camera.
  • Use Screenshot to extract text from an image.
  • Use Paste Text to open clipboard text in reader mode.
  • Use Web Link or Safari Share to import readable article text.

Troubleshooting

  • If OCR finds no text, try a clearer image with good lighting and sharper text.
  • If a web article cannot be imported, the website may block article extraction or require login.
  • If a document cannot be read, try exporting it as PDF, TXT, RTF, Markdown, or HTML.
  • If Safari Share does not appear, restart the device and confirm the app is installed.
  • If the reader opens blank content, try importing a different file or paste the text directly.

Privacy and Content

ReadFlow Speed Reader is designed for user-provided content. It does not distribute copyrighted books. OCR and reading workflows are processed locally where possible.
